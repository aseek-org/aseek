## i18n

- All copy in the `I18N` dictionary in `main.js`; elements bound via `data-i18n`.
- 12 languages, order: en, zh, es, fr, de, pt, ru, ar, hi, bn, ur, ja (ar/ur are RTL -> `dir="rtl"`).
- Language chooser is a **modal** driven by the `LANGS` array — the list builds itself, so adding a
  language means only: `LANGS` entry (+ `rtl: true` if RTL) and an `I18N` entry.
- Default: localStorage (`aseek-lang`) > browser language > fallback en.
- **Static text in `index.html` mirrors `I18N.en`. Changing one requires changing the other.**
- French copy uses curly quotes to avoid clashing with JS single quotes.
- Badge subtitles stay English in every language (design element).

## Gotchas

- Repo README was UTF-16LE with BOM (unreadable by Read) — converted to UTF-8; now written in English.
- The preview tool injects `data-page-node-id` into `index.html`, so Edit `old_string` must include
  those attributes or match only the text between tags.
- Batch replacements were done with a script using an `[old, new, expectedCount]` table that aborts
  without writing on any mismatch — much safer than hand-editing 67 strings.
